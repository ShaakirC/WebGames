# Game Night 🎲

Quick two-player party games for one shared screen: 20 Questions, First & Last,
Chain Link and Mystery Number.

Plain HTML/CSS/JS with no build step and no dependencies. Open `index.html` locally,
or visit the hosted version on GitHub Pages.

- **Adding a game:** copy `js/games/_template.js`. See [docs/PLANNING.md](docs/PLANNING.md).
- **Architecture, game specs and roadmap:** [docs/PLANNING.md](docs/PLANNING.md).
